# DataLens Frontend

This directory is reserved for the React + Vite frontend.

Planned structure:

```text
src/
├── assets/
├── components/
├── layouts/
├── pages/
├── services/       # API client and endpoint functions
├── hooks/
├── utils/
├── App.jsx
└── main.jsx
```

The frontend has not been scaffolded yet. Keep API calls in `src/services/` and read the API base URL from a Vite environment variable.
